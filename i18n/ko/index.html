ANDROID · ANDROID AUTO · 화면 미러링

ScreenOnAuto

Android 휴대전화 화면을 Android Auto 디스플레이에 미러링하고, 미디어 버튼 제어도 지원합니다.

무료로 사용할 수 있으며, 추가 결제가 필요한 기능은 없습니다.

Android 14 이상 Google Play 베타 참여 초대 기반 — 앱은 Play 스토어에서 검색되지 않습니다. Android 13 이하 APK 다운로드 KingInstaller로 사이드로드 — 아래에 단계가 있습니다.

기능

화면 미러링

휴대전화 화면을 실시간으로 캡처해 Android Auto 헤드유닛에 미러링합니다.

미디어 세션 프록시

Android Auto의 기본 미디어 화면에서 휴대전화의 모든 미디어 앱을 제어합니다.

터치 전달 (실험적)

Android Auto 화면에서 탭, 스크롤, 플링, 핀치 줌으로 휴대전화를 조작합니다.

자동 미러링 시작

Android Auto가 연결되면 자동으로 미러링을 시작합니다.

앱 자동 실행

미러링이 시작되면 지정한 앱을 휴대전화에서 자동으로 실행합니다.

가로 모드 강제

미러링 중 휴대전화를 가로 모드로 고정하며, 화면 버튼으로 언제든 전환할 수 있습니다.

자동 화면 어둡게

미러링 중 조작이 없으면 휴대전화 밝기를 자동으로 낮춥니다 (15~120초 지연).

절전 방지

미러링 중 휴대전화 화면이 꺼지지 않도록 하고, 연결이 끊기면 자동으로 중지합니다.

실행 바로가기

Android Auto 미러링 화면에 최대 4개의 앱 실행 버튼을 추가합니다.

화면 버튼

미러링 화면의 버튼을 개별적으로 표시하거나 숨깁니다: 가로 모드 강제, 자동 화면 어둡게, 그리고 휴대전화의 뒤로 / 홈 / 최근 앱.

버튼 위치

Legacy 미러링에서 버튼을 왼쪽으로 정렬하거나, 휴대전화 내비게이션 바를 자동으로 피하게 합니다.

미러링 화면 조정

가장자리가 잘리는 헤드유닛을 위해 미러링 너비와 높이를 조정합니다.

특권 기능

선택 사항이며 사용자가 직접 켜야만 동작합니다. Shizuku 또는 루트가 필요합니다. 둘 다 없는 휴대전화에서는 달라지는 것이 전혀 없습니다 — 앱에서 이 섹션은 숨겨지고, 나머지 기능은 지금까지와 똑같이 동작합니다.

휴대전화 화면 끄기

자동 화면 어둡게가 작동할 때 휴대전화 패널을 완전히 끄고, 차량 화면에는 미러링이 계속 표시됩니다.

실제 터치 입력 주입

실제 손가락 움직임을 그대로 전달하므로 Legacy 미러링에서 길게 누르기, 드래그, 멀티터치가 동작합니다.

휴대전화 내비게이션 버튼

접근성 서비스를 전혀 켜지 않아도 뒤로 / 홈 / 최근 앱이 동작합니다. 고급 → Android Auto 화면 버튼에서 켜세요.

참고: ADB로 시작한 Shizuku 서버는 USB로 연결할 때 종료될 수 있습니다 — 연결한 직후 특권 기능이 멈춘다면 Shizuku를 다시 시작하세요.

요구 사항

  • Android 7.0 (API 24) 이상
  • 휴대전화에 Android Auto 설치
  • Android Auto를 지원하는 차량 또는 헤드유닛
  • 선택 사항: 특권 기능을 사용하려면 Shizuku 또는 루트

설치

Android 14 이상 — Google Play로 설치

Android Auto는 Play 스토어에서 설치한 앱만 실행하며, Android 14 이상에서는 KingInstaller 우회 방법이 차단됩니다. 따라서 Android Auto가 받아들이는 빌드를 얻는 방법은 Play뿐입니다. Play의 내부 테스트 트랙으로 전달될 뿐, 기능이 제한된 버전이 아닌 완전한 앱입니다.

설치는 초대 기반입니다(앱은 Play 스토어에서 검색되지 않습니다). 신청 양식과 단계별 안내는 베타 테스트 참여를 참고하세요.

Android 13 이하 — KingInstaller로 사이드로드

Android Auto는 Google Play를 통해 설치된 앱을 요구합니다. 직접 설치한 APK는 거부되지만, KingInstaller는 설치 출처를 Google Play 스토어로 보고하면서 APK를 설치합니다.

  1. KingInstaller 설치 — 릴리스 페이지에서 최신 KingInstaller.apk를 내려받고, 브라우저나 파일 관리자에 "출처를 알 수 없는 앱 설치"를 허용한 뒤 설치하세요.
  2. KingInstaller로 ScreenOnAuto 설치 — 최신 릴리스에서 최신 ScreenOnAuto-*.apk를 내려받고, KingInstaller를 열어 해당 APK를 선택한 뒤 설치를 누르세요.
  3. 권한 부여 — ScreenOnAuto를 실행하고 앱 안내에 따라 권한을 부여하세요.

Android Auto에서 확인

사이드로드든 Google Play든 설치 방법과 관계없이 동일합니다. 휴대전화에서 설정 → 연결된 기기 → Android Auto → 런처 맞춤설정을 열면 ScreenOnAuto 항목 두 개가 보여야 합니다:

이름기능
ScreenOnAuto휴대전화 화면을 전체 화면으로 미러링합니다 — 지도 영역을 대체합니다.
ScreenOnAuto (Legacy)Legacy 프로젝션 경로로 미러링합니다 — 지도와 나란히 실행할 수 있습니다.

Android Auto 버전에 따라 세 번째 항목인 ScreenOnAuto 미디어 컨트롤러가 보일 수도, 보이지 않을 수도 있습니다. 둘 다 정상입니다. 이전 버전은 자체 아이콘과 함께 표시하고, 최신 버전은 내장 미디어 패널을 직접 통합하므로 별도의 아이콘이 필요하지 않습니다. 어느 경우든 미디어 제어는 계속 작동합니다.

알려진 제한 사항

  • 미러링 중에는 휴대전화 화면이 켜져 있어야 합니다 — 미러링은 휴대전화 화면에 보이는 내용을 그대로 보여 주므로, 화면이 꺼지거나 잠긴 상태에서는 계속할 수 없습니다. 화면을 켜 두려면 절전 방지를, 화면을 끄는 대신 어둡게 해 배터리를 아끼려면 자동 화면 어둡게를 사용하세요. Shizuku 또는 루트가 있고 자동 화면 어둡게가 켜져 있다면 휴대전화 화면 끄기가 이 제한을 없애 줍니다: 미러링은 계속되면서 패널만 꺼집니다.
  • DRM으로 보호된 콘텐츠는 미러링할 수 없습니다 — Netflix나 Disney+ 같은 앱은 검은 화면으로 표시됩니다. 이는 앱이 우회할 수 없는 Android 플랫폼의 제약입니다.
  • 차량 화면의 Android Auto 내비게이션 바는 Android Auto가 직접 그리는 것이라 숨길 수 없습니다.

항상 전방을 주시하세요 — 운전 중에는 이 앱을 조작하지 마세요.
