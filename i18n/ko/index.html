ANDROID · ANDROID AUTO · 화면 미러링

ScreenOnAuto

Android 휴대전화 화면을 Android Auto 디스플레이에 미러링하고, 미디어 버튼 제어도 지원합니다.

무료로 사용할 수 있으며, 추가 결제가 필요한 기능은 없습니다.

Android 14 이상 Google Play에서 설치 30분마다 신청하고 25분 안에 설치하세요. Android 13 이하 APK 다운로드 KingInstaller로 사이드로드 — 아래에 단계가 있습니다.

기능

화면 미러링

휴대전화 화면을 차량 디스플레이에 표시합니다 — 전체 화면 또는 지도와 나란히.

미디어 제어

Android Auto 자체 미디어 패널에서 휴대전화의 모든 미디어 앱을 제어합니다.

자동 미러링 시작

차량이 연결되면 미러링이 시작되고, 지정한 앱을 열 수 있으며, 휴대전화에 앱이 뜨지 않도록 백그라운드에서 시작할 수도 있습니다.

이 앱만 미러링 (Android 15+)

화면 전체 대신 앱 하나만 차량으로 보냅니다.

화면 버튼

차량 화면의 앱 바로가기와 가로 모드 강제, 자동 화면 어둡게, 뒤로 / 홈 / 최근 앱 버튼.

화면과 배터리

가로 모드 강제(양방향), 대기 시 자동으로 어둡게, 미러링 중 휴대전화 깨어 있게 유지.

차량 화면에 맞추기

헤드 유닛이 잘라내는 가장자리를 보정하고, 분할 화면에서도 왜곡되지 않게 합니다.

외부 제어

Tasker, 바로가기 또는 ADB로 미러링을 시작하거나 중지합니다. 작동 방식 →

터치 전달 (실험적)

차량 화면에서 휴대전화를 탭하고 스크롤합니다.

특권 기능

선택 사항 — Shizuku 또는 루트가 필요합니다. 둘 다 없어도 나머지 기능은 그대로 작동합니다.

휴대전화 화면 끄기

차량에는 미러링이 계속 표시되는 동안 휴대전화 패널이 꺼집니다.

실제 터치 입력 주입

차량 화면에서 길게 누르기, 드래그, 멀티 핑거 제스처를 사용할 수 있습니다. 가상 터치스크린을 켜면 GMD 같은 제스처 앱도 이를 인식합니다.

휴대전화 내비게이션 버튼

접근성 서비스 없이 뒤로 / 홈 / 최근 앱 버튼을 사용합니다.

휴대전화 화면을 차량 화면 비율에 맞추기

미러링 중 휴대전화를 차량의 화면 비율로 맞춰 검은 여백과 왜곡을 없앱니다.

차량에 연결하자 Shizuku가 멈췄거나 화면이 다시 켜지지 않나요? 문제 해결을 참고하세요.

요구 사항

  • Android 7.0 (API 24) 이상
  • 휴대전화에 Android Auto 설치
  • Android Auto를 지원하는 차량 또는 헤드유닛
  • 선택 사항: 특권 기능을 사용하려면 Shizuku 또는 루트

설치

Android 14 이상 — Google Play로 설치

Android Auto는 Play 스토어에서 설치한 앱만 실행하며, Android 14 이상에서는 KingInstaller 우회 방법이 차단됩니다. 따라서 Google Play 내부 테스트로 설치하세요. GitHub 버전과 같은 전체 앱이지만 Play 스토어에서 검색되지는 않습니다. 설치 페이지에서 신청하세요. 30분마다 새 회차가 열리며, 회차가 시작되면 설치 링크가 나타납니다. 전체 단계: 베타 테스트 참여.

Android 13 이하 — KingInstaller로 사이드로드

Android Auto는 Google Play를 통해 설치된 앱을 요구합니다. 직접 설치한 APK는 거부되지만, KingInstaller는 설치 출처를 Google Play 스토어로 보고하면서 APK를 설치합니다.

  1. KingInstaller 설치 — 릴리스 페이지에서 최신 KingInstaller.apk를 내려받고, 브라우저나 파일 관리자에 "출처를 알 수 없는 앱 설치"를 허용한 뒤 설치하세요.
  2. KingInstaller로 ScreenOnAuto 설치 — 최신 릴리스에서 최신 ScreenOnAuto-*.apk를 내려받고, KingInstaller를 열어 해당 APK를 선택한 뒤 설치를 누르세요.
  3. 권한 부여 — ScreenOnAuto를 실행하고 앱 안내에 따라 권한을 부여하세요.

Android Auto에서 확인

사이드로드든 Google Play든 설치 방법과 관계없이 동일합니다. 휴대전화에서 설정 → 연결된 기기 → Android Auto → 런처 맞춤설정을 열면 ScreenOnAuto 항목 두 개가 보여야 합니다:

이름기능
ScreenOnAuto휴대전화 화면을 전체 화면으로 미러링합니다 — 지도 영역을 대체합니다.
ScreenOnAuto (Legacy)Legacy 프로젝션 경로로 미러링합니다 — 지도와 나란히 실행할 수 있습니다.

이전 버전의 Android Auto에서는 세 번째 항목인 ScreenOnAuto 미디어 컨트롤러도 표시됩니다. 보이지 않아도 정상이며, 미디어 제어는 그대로 작동합니다.

준비되셨나요? 차량에서 미러링을 시작하는 방법은 사용 방법을 참고하세요.

팁: 실행할 때마다 나오는 화면 캡처 대화상자를 건너뛰려면 ADB로 미리 권한을 부여하세요 — ADB로 미러링 권한 부여를 참고하세요. 이것으로 이 앱만 미러링도 사용할 수 있게 됩니다.

알려진 제한 사항

  • 미러링 중에는 휴대전화 화면이 켜져 있어야 합니다 — 미러링은 휴대전화 화면에 보이는 내용을 보여 줍니다. 절전 방지로 화면을 켜 두고 자동 화면 어둡게로 배터리를 아끼세요. Shizuku 또는 루트가 있으면 휴대전화 화면 끄기로 이 제한을 없앨 수 있습니다.
  • DRM으로 보호된 콘텐츠는 미러링할 수 없습니다 — Netflix나 Disney+ 같은 앱은 검은 화면으로 표시됩니다. 이는 앱이 우회할 수 없는 Android 플랫폼의 제약입니다.
  • 차량 화면의 Android Auto 내비게이션 바는 Android Auto가 직접 그리는 것이라 숨길 수 없습니다.

항상 전방을 주시하세요 — 운전 중에는 이 앱을 조작하지 마세요.
