# プライバシーポリシー

ScreenOnAuto は Chih-En Liu が開発した Android アプリで、スマホの画面を Android Auto の車載ディスプレイにミラーリングします。このポリシーは、アプリとそのウェブサイト screenonauto.lzn.idv.tw（`/join/` のインストールページを含む）に適用されます。

**まとめ：このアプリは個人データを収集せず、どのサーバーにも保存せず、誰とも共有しません。**

## アプリ

### インターネットへのアクセスなし

ScreenOnAuto は Android のインターネットの権限を要求しないため、スマホの外へデータを送信できません。広告、アクセス解析、クラッシュレポート、トラッキングのライブラリは含まれておらず、アカウントも不要です。

### 各権限の用途

以下の処理はすべてスマホの中で行われます。スマホから出ていくものは、Android Auto の接続を通じて車へ送られるだけです。

| 権限 | 用途 |
|---|---|
| 画面キャプチャ（MediaProjection） | スマホの画面、または 1 つのアプリをキャプチャして車の画面に表示します。録画や保存は一切しません。 |
| 通知へのアクセス | メディア操作のために、アクティブなメディアセッション（再生中の内容、再生／一時停止、スキップ）を読み取ります。通知の内容は読み取りも保存もしません。 |
| ユーザー補助サービス | 車の画面でのタッチをスマホでのタッチに変換し、戻る / ホーム / 最近のアプリのボタンを処理します。画面の内容は読み取らず、受け取ったユーザー補助イベントも使いません。 |
| 他のアプリの上に重ねて表示 | 自動減光、画面の向きを固定、夜間減光のオーバーレイ。 |
| システム設定の変更 | Android 16 以降のタブレットモードで、ミラーリング中に画面の回転を固定します。 |
| Shizuku または root（任意） | 特権機能：スマホの画面の消灯、タッチ入力の注入、スマホのナビゲーションボタン、ミラーリング中のスマホの画面サイズ、密度、テーマ、文字サイズ、ナビゲーション モード、デフォルトのホームアプリ（ランチャー）の変更。ミラーリングが終わると、スマホ本来の値に戻します。 |

### 保存されるデータ

設定と、ミラーリング後にアプリが元に戻すスマホ本来の設定値（画面サイズ、テーマ、デフォルトのホームアプリなど）は、スマホ内のアプリ専用ストレージに保存されます。アプリをアンインストールすると削除されます。Android のバックアップがオンの場合、ほとんどのアプリと同じく、Android がこれらの設定をあなた自身の Google アカウントのバックアップに含めたり、新しいスマホへのデータ移行時にコピーしたりすることがあります。

### Google Play

Google Play から ScreenOnAuto をインストールした場合、Google が端末の設定に応じてクラッシュやパフォーマンスの統計を収集し、集計した形でデベロッパーに提供することがあります（Android Vitals）。これは [Google プライバシー ポリシー](https://policies.google.com/privacy?hl=ja)に基づいて Google が扱います。

## ウェブサイト

### インストールページ（`/join/`）

テスターになるには、インストールページで Google にログインします。使うのはアカウントのメールアドレスだけで、その回の Google Play テスターリストに追加するためだけに使います。メールを送ることはなく、リストはその回のインストール時間が終わると削除されます。

ログインは Google が処理します。ページは Google のログイン用スクリプトを読み込み、このスクリプトは Google の Cookie を設定することがあり、あなたの IP アドレスを受け取ります。これは [Google プライバシー ポリシー](https://policies.google.com/privacy?hl=ja)に基づきます。ログイン後、Google から返されるログイントークン（メールアドレスなどの Google アカウント情報を含む）は、タブを閉じるまでブラウザのセッションストレージに保存されます。ページはこれをインストールサーバー（api.screenonauto.lzn.idv.tw）に送ります。サーバーはリクエストごとに IP アドレスを受け取りますが、IP アドレスやメールアドレスは記録しません。

### その他

インストールページでのログインを除き、サイトではアクセス解析、トラッキング、Cookie を使っていません。ライト／ダークのテーマ選択は、ブラウザのローカルストレージに保存されます。サイトは GitHub Pages でホストされ、フォントを Google Fonts から読み込むため、ページを配信する際に GitHub と Google がそれぞれのプライバシーポリシーに基づいてあなたの IP アドレスを受け取ります。

## 送っていただいたバグレポート

バグレポートやログを送る場合（たとえば GitHub の issue に Google ドライブのリンクを貼る場合）、端末やインストールされているアプリに関する情報が含まれることがあります。これは問題の調査だけに使い、調査が終わったら削除します。GitHub の issue は公開されているため、個人情報は投稿しないでください。

## お子様について

ScreenOnAuto は 13 歳未満のお子様を対象としておらず、誰のデータも意図的に収集することはありません。

## 変更について

このポリシーを変更した場合は、新しい版をこのページで公開し、下の「最終更新」の日付も変わります。
