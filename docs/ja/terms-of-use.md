# 利用規約

この規約は、Chih-En Liu が開発した Android アプリ ScreenOnAuto と、そのウェブサイト screenonauto.lzn.idv.tw（`/join/` のインストールページを含む）に適用されます。ScreenOnAuto をインストールまたは使用すると、この規約に同意したものとみなされます。同意できない場合は、アプリを使用しないでください。

## アプリの利用

ScreenOnAuto は無料で使えます。アプリを改変または逆コンパイルして再配布すること、またアプリやアプリと称するものを ScreenOnAuto の名前で再公開すること（アプリストアを含む）は禁止です。公式のダウンロードページへのリンクを共有するのは大歓迎です。

アプリは公式の入手先からのみ入手してください：[GitHub のリリースページ](https://github.com/slzn/ScreenOnAuto-releases/releases)と、[インストールページ](/join/?lang=ja)の Google Play テストプログラムです。ほかの場所で入手したファイルは改ざんされている可能性があります。

## 運転中の安全

車内で ScreenOnAuto をどう使うかは、あなたの責任です。

- 常に前方を見て運転してください。運転中にアプリを操作したり、アプリが表示する内容を見たりしないでください。
- 運転する地域の交通法規を守ってください。多くの地域では、どのアプリが表示しているかにかかわらず、運転中に動画を見たり画面を操作したりすることは違法です。
- タクシー、ライドシェア、配達など、仕事で運転する場合は、雇用主やプラットフォームの規則も守ってください。
- ミラーリングは出発前に設定するか、同乗者に操作してもらってください。

運転中のアプリの使用による事故、罰金、その他の結果について、デベロッパーは責任を負いません。

## システム設定を変更する機能

一部の機能は、ミラーリング中にスマホのシステム設定を変更し、ミラーリングが終わると元に戻します。

- Shizuku または root を使う場合：画面サイズ、密度、テーマ、フォントサイズ、ナビゲーションモード
- Android 16 以降のタブレットモードでの画面の向きを固定：システムの回転ロック

元に戻す処理は失敗することがあります。たとえば、ケーブルを抜いた瞬間に Shizuku との接続が切れた場合です。これらの機能は自己責任でご利用ください。設定が変更されたままになった場合は、スマホの設定アプリで元に戻してください。画面サイズと密度は `adb shell wm size reset` と `adb shell wm density reset` でもリセットできます。

同じく Shizuku または root が必要な「スマホの画面を消灯する」は、ミラーリング中にスマホの画面を消灯します。画面が再び点灯しない場合は、スマホの電源ボタンを 2 回押してください。
