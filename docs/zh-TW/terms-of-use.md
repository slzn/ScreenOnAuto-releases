## 開車安全

你在車上如何使用 ScreenOnAuto，由你自行負責。

- 開車時請專注路況。行車中請勿操作這個 app，也不要觀看它顯示的內容。
- 請遵守你所在地的交通法規。在許多地方，開車時觀看影片或操作螢幕是違法的，不論顯示內容的是哪個 app。
- 如果你以駕駛為業，例如計程車、叫車平台或外送，也請遵守雇主或平台的規定。
- 請在出發前設定好鏡像，或交給乘客操作。

對於開車時使用這個 app 所造成的事故、罰款或任何其他後果，開發者概不負責。

## 會變更系統設定的功能

部分功能會在鏡像期間變更手機的系統設定，並在鏡像結束後還原：

- 使用 Shizuku 或 root 時：螢幕尺寸、密度、主題、字型大小、導覽模式與預設啟動器（主畫面應用程式）；
- Android 16 以上平板模式下的鎖定方向：系統的旋轉鎖定。

還原有可能失敗，例如拔線的瞬間與 Shizuku 的連線剛好中斷。使用這些功能的風險由你自行承擔。如果某項設定沒有還原，請到手機的「設定」app 改回來。螢幕尺寸與密度也可以用 `adb shell wm size reset` 和 `adb shell wm density reset` 重設。

同樣需要 Shizuku 或 root 的「關閉手機螢幕」，會在鏡像期間關閉手機的螢幕。如果螢幕沒有重新亮起，請連按手機電源鍵兩次。
