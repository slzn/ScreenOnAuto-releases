# 개인정보처리방침

ScreenOnAuto는 Chih-En Liu가 개발한 Android 앱으로, 휴대전화 화면을 Android Auto 차량 디스플레이에 미러링합니다. 이 방침은 앱과 웹사이트 screenonauto.lzn.idv.tw(`/join/` 설치 페이지 포함)에 적용됩니다.

**요약: 이 앱은 개인정보를 수집하지 않고, 어떤 서버에도 저장하지 않으며, 누구와도 공유하지 않습니다.**

## 앱

### 인터넷 접근 없음

ScreenOnAuto는 Android의 인터넷 권한을 요청하지 않으므로 휴대전화 밖으로 데이터를 보낼 수 없습니다. 광고, 분석, 비정상 종료 보고, 추적 라이브러리가 없으며 계정도 필요하지 않습니다.

### 권한별 사용 목적

아래의 모든 처리는 휴대전화 안에서 이루어집니다. 휴대전화 밖으로 나가는 것은 Android Auto 연결을 통해 차량으로만 전달됩니다.

| 권한 | 사용 목적 |
|---|---|
| 화면 캡처 (MediaProjection) | 휴대전화 화면 또는 앱 하나를 캡처해 차량 화면에 표시합니다. 아무것도 녹화하거나 저장하지 않습니다. |
| 알림 접근 권한 | 미디어 컨트롤을 위해 활성 미디어 세션(재생 중인 내용, 재생/일시중지, 건너뛰기)을 읽습니다. 알림 내용은 읽거나 저장하지 않습니다. |
| 접근성 서비스 | 차량 화면의 터치를 휴대전화의 터치로 바꾸고, 뒤로 / 홈 / 최근 앱 버튼을 처리합니다. 화면 내용을 읽지 않으며, 받은 접근성 이벤트도 사용하지 않습니다. |
| 다른 앱 위에 표시 | 자동 화면 어둡게, 화면 방향 고정, 야간 어둡게 오버레이. |
| 시스템 설정 수정 | Android 16 이상의 태블릿 모드에서 미러링 중 화면 회전을 고정합니다. |
| Shizuku 또는 루트 (선택) | 특권 기능: 휴대전화 화면 끄기, 터치 입력 주입, 휴대전화 탐색 버튼, 그리고 미러링 중 휴대전화의 화면 크기, 밀도, 테마, 글꼴 크기, 탐색 모드, 기본 런처(홈 앱) 변경. 미러링이 끝나면 휴대전화의 원래 값으로 되돌립니다. |

### 저장되는 데이터

설정값과, 미러링 후 앱이 되돌릴 휴대전화의 원래 값(화면 크기, 테마, 기본 런처 등)은 휴대전화 안의 앱 전용 저장공간에 저장됩니다. 앱을 삭제하면 함께 지워집니다. Android 백업이 켜져 있으면, Android가 대부분의 앱과 마찬가지로 이 설정을 사용자 본인의 Google 계정 백업에 포함하거나, 새 휴대전화로 데이터를 옮길 때 함께 복사할 수 있습니다.

### Google Play

Google Play에서 ScreenOnAuto를 설치한 경우, Google은 기기 설정에 따라 비정상 종료 및 성능 통계를 수집하고 이를 집계된 형태로 개발자에게 제공할 수 있습니다(Android vitals). 이는 [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)에 따라 Google이 처리합니다.

## 웹사이트

### 설치 페이지 (`/join/`)

테스터가 되려면 설치 페이지에서 Google로 로그인합니다. 계정의 이메일 주소만 사용하며, 해당 회차의 Google Play 테스터 목록에 추가하는 데에만 씁니다. 이메일을 보내지 않으며, 이 목록은 회차의 설치 시간이 끝나면 삭제됩니다.

로그인은 Google이 처리합니다. 페이지는 Google의 로그인 스크립트를 불러오며, 이 스크립트는 Google 쿠키를 설정할 수 있고 사용자의 IP 주소를 받습니다. 이는 [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)에 따릅니다. 로그인하면 Google이 돌려준 로그인 토큰(이메일 주소 등 Google 계정 정보 포함)이 탭을 닫을 때까지 브라우저의 세션 저장소에 보관됩니다. 페이지는 이 토큰을 설치 서버(api.screenonauto.lzn.idv.tw)로 보내며, 서버는 요청마다 IP 주소를 받지만 IP 주소와 이메일 주소를 기록하지 않습니다.

### 그 밖의 부분

설치 페이지의 로그인을 제외하면, 사이트는 분석 도구, 추적, 쿠키를 사용하지 않습니다. 밝은/어두운 테마 선택은 브라우저의 로컬 저장소에 보관됩니다. 사이트는 GitHub Pages에서 호스팅되고 글꼴을 Google Fonts에서 불러오므로, 페이지를 제공하는 과정에서 GitHub와 Google이 각자의 개인정보처리방침에 따라 사용자의 IP 주소를 받게 됩니다.

## 보내 주신 버그 보고서

버그 보고서나 로그를 보내기로 한 경우(예: GitHub issue에 Google Drive 링크 첨부), 여기에는 기기와 기기에 설치된 앱에 관한 정보가 포함될 수 있습니다. 이는 문제를 조사하는 데에만 사용되며, 조사가 끝나면 삭제됩니다. GitHub issue는 공개되므로 개인정보를 올리지 마세요.

## 아동

ScreenOnAuto는 13세 미만 아동을 대상으로 하지 않으며, 누구의 데이터도 알면서 수집하지 않습니다.
