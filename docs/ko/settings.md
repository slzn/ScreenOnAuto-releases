# 설정 안내

이 페이지는 앱의 설정 화면을 위에서 아래로 따라가며 각 설정이 하는 일, 언제 켜면 좋은지, 그리고 한 줄 설명에는 빠져 있는 한계를 설명합니다. 앱을 처음 쓴다면 [사용 방법](/docs/ko/how-to-use/)부터 보세요.

## 메인 화면 {#main}

### 상태 패널 {#mirror}

맨 위의 어두운 패널입니다. 첫 줄에는 Android Auto가 연결되어 있는지, 연결되어 있다면 측정한 차량 화면 크기가 표시됩니다. 그 아래에는 현재 상태와 <span class="sp-ui-go">미러링 시작</span> / <span class="sp-ui-go stop"><svg viewBox="0 0 12 12" aria-hidden="true"><rect width="12" height="12" rx="2"/></svg>미러링 중지</span> 버튼이 있습니다. **미러링 시작**을 누르면 휴대전화에 Android의 화면 캡처 대화상자가 나타나고, **지금 시작**을 누르면 미러링이 시작됩니다.

권한이 빠져 있으면 패널 아래쪽에 호박색 줄로 알려 줍니다. 누르면 [권한](#category_permissions)으로 스크롤됩니다.

### 자동 미러링 시작 {#auto_start_mirror}

이 설정을 켜면 차량에서 미러링을 시작할 수 있습니다. 진행 순서는 다음과 같습니다(‘직접’ 표시가 있는 단계는 직접 하고, 나머지는 저절로 진행됩니다).

1. <span class="sp-who you">직접</span> 차량 화면에서 ScreenOnAuto 항목(<img class="sp-entry" src="/images/icon_launcher.png" alt="ScreenOnAuto 아이콘"> 또는 <img class="sp-entry" src="/images/icon_legacy.png" alt="ScreenOnAuto (Legacy) 아이콘">) 중 하나를 누릅니다.
2. 휴대전화가 절전 상태라면 화면이 켜집니다.
3. 휴대전화에서 ScreenOnAuto 설정 화면이 열리고 <span class="sp-ui-go">미러링 시작</span>을 대신 눌러 줍니다.
4. <span class="sp-who you">직접</span> Android가 화면 캡처 대화상자를 띄우면 **지금 시작**으로 허용합니다. 휴대전화가 PIN, 패턴 또는 지문으로 잠겨 있다면 먼저 잠금을 해제하세요. 그러면 대화상자가 나타납니다.
5. 미러링이 시작되고 휴대전화 화면이 차량에 나타납니다.

> **💡 팁**
> - **매번 허용하기 번거롭다면?** [ADB로 미러링 권한 부여](/docs/ko/grant-mirror-permission-via-adb/)를 한 번 해 두면 대화상자가 더 이상 나타나지 않아 4단계가 사라집니다(휴대전화 잠금을 해제할 때까지 차량에는 잠금 화면이 표시됩니다).
> - **설정 화면이 뜨지 않았으면 한다면?** 고급의 [백그라운드에서 미러링 시작](#silent_car_start)을 켜세요. 3단계에서 ScreenOnAuto를 열지 않고 바로 캡처 대화상자로 넘어갑니다. 둘 다 켜면 1단계만 하면 되고, 휴대전화에는 아무것도 나타나지 않습니다.

이 설정이 꺼져 있으면 3단계를 직접 해야 합니다. 차량에서 항목을 눌러도 ‘휴대폰에서 미러링 시작’ 대기 화면만 표시되므로, 휴대전화에서 ScreenOnAuto를 열고 <span class="sp-ui-go">미러링 시작</span>을 직접 누른 다음 위와 같이 4단계를 진행합니다.

### 절전 방지 {#keep_awake}

미러링하는 동안 휴대전화 화면이 꺼지지 않게 합니다. 미러링되는 것이 곧 휴대전화 화면이므로, 화면이 꺼지면 차량의 화면도 멈춥니다. 화면을 켜 둘 뿐 밝기를 올리지는 않으므로 [자동 화면 어둡게](#auto_dim)와 함께 쓰기 좋습니다. 화면은 켜진 채로 있고, 사용하지 않을 때는 어두워집니다.

### 연결 해제 시 중지 {#stop_on_disconnect}

Android Auto 연결이 끊기면 미러링을 중지합니다(기본값 켜짐). 끄면 차에서 내린 뒤에도 직접 중지할 때까지 미러링이 백그라운드에서 계속 실행됩니다.

### 자동 화면 어둡게 {#auto_dim}

미러링 중 한동안 아무도 휴대전화를 만지지 않으면 밝기를 최저로 낮춥니다. 배터리를 아끼고 눈부심도 줄여 줍니다. 어두워지는 것은 휴대전화의 백라이트뿐이고, 차량의 화면 밝기는 그대로입니다. 휴대전화를 만지면 밝기가 돌아옵니다.

- [다른 앱 위에 표시](#overlay_access) 권한이 필요합니다.
- 차량 화면을 조작하는 것([터치 전달](#accessibility_access))은 휴대전화를 만진 것으로 치지 않으므로 휴대전화가 다시 밝아지지 않습니다.
- 휴대전화가 잠금 화면에 머물러 있는 동안에는 어두워지지 않습니다. 잠금을 해제하거나 만지면 그때부터 시간을 셉니다.
- Shizuku 또는 Root가 있으면 어둡게 하는 대신 휴대전화 화면을 끌 수도 있습니다. [휴대전화 화면 끄기](#root_screen_off)를 참고하세요.

### 어둡게 하기까지 대기 시간 {#auto_dim_delay}

휴대전화가 얼마나 사용되지 않아야 어두워지는지 정합니다: 15초, 30초(기본값), 60초, 120초. [자동 화면 어둡게](#auto_dim)가 켜져 있어야 합니다.

### 앱 자동 실행 {#auto_launch_package}

미러링과 Android Auto가 모두 활성화되면 휴대전화에서 앱(예: 지도나 음악 플레이어)을 바로 엽니다. 목록 맨 위의 **기본 홈 화면**을 고르면 지금 쓰는 홈 화면 앱이 열리므로, 런처를 바꿔도 그대로 작동합니다.

### 이 앱만 미러링 {#single_app_mirror}

휴대전화 화면 전체 대신 위의 [앱 자동 실행](#auto_launch_package)에서 고른 앱만 차량으로 보냅니다. 휴대전화에서 다른 앱으로 전환하면 다시 돌아올 때까지 차량 화면이 비어 있습니다. 동승자가 보는 화면이나 알림이 차량에 나타나지 않게 하고 싶을 때 유용합니다.

이 줄은 **Android 15 이상**에서 [ADB로 미러링 권한을 부여](/docs/ko/grant-mirror-permission-via-adb/)한 뒤에만 나타납니다. 앱 자동 실행에서 앱을 고르기 전까지는 회색으로 비활성화됩니다.

**언제 필요한가요?**

- **ADB로 권한을 부여하지 않았다면 필요 없습니다.** Android 14부터는 미러링을 시작할 때마다 나타나는 캡처 대화상자에서 전체 화면을 공유할지 앱 하나만 공유할지 고를 수 있습니다. 거기서 앱을 고르면 그 앱만 미러링됩니다. Android 13 이하의 대화상자에는 이런 선택지가 없어 항상 전체 화면이 미러링됩니다.
- **ADB로 권한을 부여했다면 필요합니다.** 권한을 부여하면 대화상자가 더 이상 나타나지 않으므로 앱을 고를 곳이 없고, 항상 전체 화면이 미러링됩니다. 대화상자를 건너뛰면서 앱 하나만 미러링하려면 이 스위치를 쓰세요. 위의 [앱 자동 실행](#auto_launch_package)과 함께 쓰면 그 앱만 차량으로 보냅니다.
- 고급의 [전체 화면만 공유](#full_screen_share_only)는 대화상자에서 앱 하나를 고르는 선택지를 없애는 설정으로, 이 스위치를 방해하지 않습니다.

### 하위 페이지 {#subpages}

**화면 버튼**, **고급**, **특권 기능**은 각각 별도의 페이지를 열며, 아래 장에서 다룹니다: [화면 버튼](#screen_buttons), [고급](#advanced), [특권 기능](#root_features).

### 권한 {#category_permissions}

각 줄을 누르면 해당 시스템 설정 페이지가 열립니다. 오른쪽 태그는 권한이 허용되었는지 알려 줍니다.

#### 알림 접근 권한 {#notification_access}

‘ScreenOnAuto 미디어 컨트롤러’ <img class="sp-entry" src="/images/icon_media.png" alt="ScreenOnAuto 미디어 컨트롤러 아이콘"> 가 휴대전화에서 재생 중인 것을 넘겨받게 합니다. 그러면 **스티어링 휠의 미디어 버튼**과 Android Auto의 미디어 화면으로 YouTube처럼 **자체적으로 Android Auto를 지원하지 않는 플레이어**를 제어할 수 있습니다. 이전/다음, 재생/일시정지 모두 작동합니다.

- 읽는 것은 재생 중인 항목(미디어 세션)뿐이며, 알림 내용은 절대 읽지 않습니다.
- 자체적으로 Android Auto를 지원하는 음악 앱(YouTube Music, Spotify 등)은 Android Auto에 직접 연결되므로 관여하지 않습니다.
- 이 권한이 없으면 버튼 입력은 시스템이 활성 상태로 판단한 플레이어로 갑니다. 플레이어를 여러 개 열어 두었다면 엉뚱한 플레이어가 반응할 수 있습니다.
- 이전 버전의 Android Auto는 앱 런처에 ‘ScreenOnAuto 미디어 컨트롤러’ 항목을 따로 표시하지만, 최신 버전에는 없습니다. 이는 정상이며, 어느 쪽이든 미디어 제어는 작동합니다.

#### 다른 앱 위에 표시 {#overlay_access}

[자동 화면 어둡게](#auto_dim), 화면 방향 고정([연결 시 화면 방향 고정](#force_landscape)과 [차량 버튼](#map_action_force_landscape)), [야간 어둡게](#night_dim)에 필요합니다.

#### 시스템 설정 수정 {#write_settings_access}

**Android 16 이상**에서만 표시됩니다. 휴대전화가 태블릿 모드(짧은 쪽이 600dp 이상 — 폴더블의 안쪽 화면이나 [휴대전화 표시 밀도](#phone_density)를 낮춘 경우)일 때 Android 16은 앱이 요청하는 화면 방향을 무시하므로, 화면 방향 고정은 대신 시스템의 회전 잠금을 사용하며 여기에 이 권한이 필요합니다. 고정이 끝나면 원래의 자동 회전 설정이 돌아옵니다.

#### 터치 전달 {#accessibility_access}

차량 화면에서의 탭, 스와이프, 핀치를 Android 접근성 서비스를 통해 휴대전화로 전달합니다. 두 미러링 모두 여기서 지원하는 제스처는 같습니다: 탭, 스크롤(목록 넘기기), 플링, 핀치 줌.

Shizuku 또는 Root가 있으면 대신 [실제 터치 입력 주입](#root_touch_injection)을 쓸 수 있습니다. 차량 화면의 터치가 실제 손가락 움직임으로 휴대전화에 전달되므로 휴대전화를 직접 쓰는 듯한 느낌입니다. 접근성 서비스로는 할 수 없는 **길게 누르기**, **누른 채 끌기**(예: 홈 화면 아이콘 옮기기), **여러 손가락 제스처**도 작동하지만, <span class="sp-mirror legacy">‘ScreenOnAuto (Legacy)’ 미러링</span>에서만 가능합니다.

버전(누르면 복사됨), GitHub 및 후원 링크, 개인정보처리방침, 이용 약관, 서드파티 라이선스입니다.

## 화면 버튼 {#screen_buttons}

차량 화면에 버튼으로 나타날 수 있는 모든 것은 이 페이지에서 설정합니다.

### 실행 바로가기 {#category_shortcuts}

차량 화면에 앱 바로가기를 최대 4개 둘 수 있습니다. 하나를 누르면 휴대전화에서 그 앱이 열리고, 따라서 차량에도 나타납니다.

- 줄을 눌러 앱을 고르고, 오른쪽 스위치로 차량에 표시할지 정합니다. 여기서도 **기본 홈 화면**을 고를 수 있어 ‘홈으로’ 버튼처럼 쓸 수 있습니다.
- 설정한 바로가기를 **길게 누르면** 차량에 표시되는 글자(최대 30자)를 바꿀 수 있습니다. 글자를 비우면 <span class="sp-mirror legacy">‘ScreenOnAuto (Legacy)’ 미러링</span>에서는 앱 아이콘만 표시됩니다.
- 바로가기는 미러링 화면의 **위쪽**에 나타나며, 어느 쪽에 놓이는지는 미러링에 따라 다릅니다:
  - <span class="sp-mirror nav">‘ScreenOnAuto’ 미러링</span>: Android Auto의 지도 화면 템플릿을 사용하므로 바로가기는 Android Auto가 직접 그리는 텍스트 버튼(아이콘 없음)이고, 위치도 Android Auto가 정합니다. 앱에서는 옮길 수 없습니다. Android Auto의 운전석 위치 설정에 따라 좌우가 바뀔 수도 있지만 보장되지는 않습니다.
  - <span class="sp-mirror legacy">‘ScreenOnAuto (Legacy)’ 미러링</span>: 앱이 아이콘이 있는 버튼으로 직접 그리며, 기본 위치는 **오른쪽 위**입니다. [버튼 왼쪽 정렬](#legacy_buttons_left)로 왼쪽 위로 옮길 수 있고, [간격 설정](#legacy_gaps)으로 가장자리와의 거리를 미세 조정할 수 있습니다.
- 바로가기는 계속 화면에 남아 있지 않습니다. <span class="sp-mirror legacy">‘ScreenOnAuto (Legacy)’ 미러링</span>에서는 5초 동안 조작이 없으면 [기능 버튼](#category_control_buttons)과 함께 숨겨졌다가 차량 화면을 만지면 다시 나타납니다. <span class="sp-mirror nav">‘ScreenOnAuto’ 미러링</span>에서는 언제 숨길지 Android Auto가 정합니다.

### 기능 버튼 {#category_control_buttons}

미러링 화면 위에 표시되는 둥근 버튼으로, 어느 미러링이든 한 번에 최대 4개까지 쓸 수 있습니다.

- 위치는 미러링에 따라 다릅니다:
  - <span class="sp-mirror nav">‘ScreenOnAuto’ 미러링</span>: Android Auto 지도 화면 템플릿의 버튼 줄로, Android Auto가 **오른쪽 아래 또는 왼쪽 아래**에 그립니다. 어느 쪽인지는 Android Auto가 정하며 앱에서 옮길 수 없습니다. [실행 바로가기](#category_shortcuts)와 마찬가지로 운전석 위치 설정에 따라 좌우가 바뀔 수도 있지만 보장되지는 않습니다.
  - <span class="sp-mirror legacy">‘ScreenOnAuto (Legacy)’ 미러링</span>: 앱이 직접 그리는 세로 줄로, 기본 위치는 **오른쪽 아래**입니다. [버튼 왼쪽 정렬](#legacy_buttons_left)로 왼쪽 아래로 옮길 수 있고, [간격 설정](#legacy_gaps)으로 가장자리와의 거리를 미세 조정할 수 있습니다.
- 자동 숨김: <span class="sp-mirror legacy">‘ScreenOnAuto (Legacy)’ 미러링</span>에서는 5초 동안 조작이 없으면 기능 버튼이 바로가기와 함께 숨겨졌다가 차량 화면을 만지면 다시 나타납니다. <span class="sp-mirror nav">‘ScreenOnAuto’ 미러링</span>에서는 언제 숨길지 Android Auto가 정합니다.

#### 화면 방향 고정 버튼 {#map_action_force_landscape}

[연결 시 화면 방향 고정](#force_landscape) 설정은 바꾸지 않고 지금 당장 화면 방향 고정을 켜거나 끕니다. 다음에 연결할 때는 다시 설정을 따릅니다. 기본값은 켜짐입니다.

#### 자동 어둡게 버튼 {#map_action_auto_dim}

[자동 화면 어둡게](#auto_dim)를 켜거나 끕니다. 설정 화면에 있는 것과 같은 스위치입니다. 휴대전화 화면이 [꺼져](#root_screen_off) 있을 때 화면을 되살리는 가장 빠른 방법입니다.

#### 야간 어둡게 버튼 {#map_action_night_dim}

예를 들어 터널에 들어갈 때처럼 잠시 [야간 어둡게](#night_dim)를 켜거나 끕니다. 효과는 차량이 다음에 주간과 야간을 전환할 때까지 유지되며, [어둡게 할 때](#night_dim_trigger)가 ‘항상’이라면 Android Auto 연결이 끊길 때까지 유지됩니다. 어둡기는 [강도](#night_dim_strength) 설정을 따릅니다.

#### 뒤로, 홈, 최근 앱 버튼 {#map_action_nav}

휴대전화의 세 가지 탐색 키로, 휴대전화가 동작 탐색을 쓰든 버튼 탐색을 쓰든 작동합니다. Shizuku 또는 Root가 연결되어 있으면 실제 키 입력을 보내고, 그렇지 않으면 [터치 전달](#accessibility_access)이 필요합니다.

### 버튼 위치 {#category_button_placement}

이 섹션은 <span class="sp-mirror legacy">‘ScreenOnAuto (Legacy)’ 미러링</span>에만 적용됩니다. <span class="sp-mirror nav">‘ScreenOnAuto’ 미러링</span>의 버튼은 Android Auto가 그리므로 옮길 수 없습니다.

#### 버튼 왼쪽 정렬 {#legacy_buttons_left}

[기능 버튼](#category_control_buttons)과 [바로가기](#category_shortcuts)를 왼쪽으로 옮깁니다. 우핸들 차량이나 헤드유닛 자체의 조작 버튼이 오른쪽을 가릴 때 쓰세요.

#### 휴대폰 내비게이션 바 피하기 {#legacy_buttons_dodge_nav}

휴대전화의 내비게이션 바가 미러링 화면에 보일 때 버튼을 그 바깥으로 옮겨 두 버튼 묶음이 겹치지 않게 합니다. Android 11 이상이 필요합니다(그보다 오래된 휴대전화에는 이 줄이 표시되지 않습니다). 켜져 있는 동안에는 아래 네 가지 간격이 회색으로 비활성화됩니다. 둘 중 한 가지 배치 방식만 쓸 수 있습니다.

#### 버튼과 바로가기 간격 {#legacy_gaps}

dp 단위의 네 가지 간격(0–400, 기본값 16)입니다: 기능 버튼과 측면·아래쪽 가장자리 사이, 바로가기와 측면·위쪽 가장자리 사이의 간격입니다. 헤드유닛 자체의 버튼 아래에 가려진 ScreenOnAuto 버튼을 밖으로 빼낼 때 씁니다. 값이 너무 커서 들어갈 자리가 없으면 버튼은 화면 밖으로 사라지지 않고 화면 안에 머뭅니다.

## 고급 {#advanced}

### 화면 방향 {#category_orientation}

#### 연결 시 화면 방향 고정 {#force_landscape}

Android Auto가 연결될 때 휴대전화를 한 방향으로 고정합니다. 휴대전화가 돌아가도 미러링 화면이 뒤집히지 않고, 가로로 둔 휴대전화가 넓은 차량 화면을 꽉 채웁니다. 연결되는 순간 한 번만 작동하며, 그 뒤에는 차량의 [화면 방향 고정 버튼](#map_action_force_landscape)으로 해제하거나 다시 적용합니다. [다른 앱 위에 표시](#overlay_access) 권한이 필요합니다.

#### 방향 {#force_orientation_mode}

어느 방향으로 고정할지 정합니다: **가로**(기본값), **세로**, 또는 **차량 화면에 맞춰 자동 감지** — 차량에서 미러링이 실제로 쓸 수 있는 영역이 가로로 길면 가로, 세로로 길면 세로입니다. 분할 화면으로 그 모양이 바뀌면 따라서 바뀝니다.

#### 가로 모드 반전 {#force_landscape_reverse}

가로로 둔 휴대전화를 반대 방향으로 돌립니다. 휴대전화를 거꾸로 잡아 주는 거치대에 맞춘 설정입니다. 세로일 때는 회색으로 비활성화됩니다.

### 화면 조정 {#category_display_adjust}

#### 직접 그리기 미러링 {#self_draw}

시스템에 확대·축소를 맡기지 않고 앱이 직접 휴대전화 화면을 차량에 그립니다. 그러면 분할 화면에서도 화면이 왜곡되지 않고, 아래의 너비/높이 조정이 연결 전에 설정하든 연결 중에 설정하든 똑같이 작동합니다. 배터리를 조금 더 사용합니다.

변경 사항은 **다음에 미러링을 시작할 때** 적용됩니다. 미러링 도중에는 일부러 전환하지 않습니다.

#### 영상 지연 {#video_delay}

화면이 소리보다 앞서 나갈 때(예: 수신 앱으로 Android Auto를 재생하는 Android 헤드유닛에서 소리가 늦는 경우) 화면을 0–2000밀리초 늦춰 둘을 맞춥니다. [직접 그리기 미러링](#self_draw)이 필요하며, 변경 사항은 바로 적용됩니다.

- 프레임을 붙잡아 두려면 메모리와 GPU를 더 씁니다. 휴대전화나 헤드유닛이 이미 버거워서 소리와 화면이 어긋나는 거라면 오히려 더 나빠질 수 있습니다.
- 탭은 지연된 화면이 아니라 **지금**의 휴대전화 화면에 작용합니다.

#### 미러링 크기 고정 {#nav_fixed_size}

<span class="sp-mirror nav">‘ScreenOnAuto’ 미러링</span> 전용입니다. 차량이 분할 화면으로 바뀌어도 미러링 크기를 유지하므로 왜곡되지 않지만, 일부가 잘릴 수 있습니다. 연결하기 전에 설정하는 것이 가장 좋습니다.

#### 버튼 표시 시 미러링 고정 {#nav_ignore_strip}

<span class="sp-mirror nav">‘ScreenOnAuto’ 미러링</span> 전용이며 기본값은 켜짐입니다. Android Auto의 버튼 줄은 저절로 나타났다 숨었다 하며, 그때마다 자리를 조금 차지합니다. 이 설정을 켜면 버튼 줄이 나타나도 미러링 크기가 바뀌며 튀지 않습니다. 분할 화면 같은 실제 레이아웃 변화는 그대로 반영됩니다. [미러링 크기 고정](#nav_fixed_size)이 켜져 있으면 회색으로 비활성화됩니다.

#### 미러링 너비 조정, 미러링 높이 조정 {#vd_gap}

차량이 미러링에 내주는 영역(아래 그림의 녹색 점선 테두리)은 휴대전화 화면과 모양이 같은 경우가 드뭅니다. 휴대전화 화면은 비율을 유지한 채 그 안에 맞게 확대·축소되므로, 맞지 않는 쪽에는 검은 띠가 남습니다. 화면이 영역보다 **넓으면**(예: 분할 화면으로 영역이 좁아진 경우) 띠는 **위아래**에, **좁으면** **좌우**에 생깁니다.

이 두 설정은 미러링을 맞춰 넣는 틀을 픽셀 단위로 키우거나 줄입니다. **음수** 값은 틀을 키웁니다. 화면이 커지고 띠가 줄어드는 대신, 화면 일부가 쓸 수 있는 영역 밖으로 넘쳐 잘립니다(그림의 빗금 부분).

- **위아래에 띠 → *너비*를 음수로.** 틀이 넓어지면 화면이 커지면서 세로로도 길어져 띠를 채웁니다.
- **좌우에 띠 → *높이*를 음수로.** 틀이 높아지면 화면이 커지면서 가로로도 넓어져 띠를 채웁니다.
- 미러링은 영역의 **왼쪽 위 모서리**에 고정되므로, 넘치는 부분은 **오른쪽** 가장자리(너비) 또는 **아래쪽**(높이) 밖으로 나갑니다. 양쪽으로 나뉘어 넘치지 않습니다. 거기서 잘린 부분은 버튼을 포함해 누를 수 없으므로, 띠가 막 사라지는 값에서 멈추세요.
- **양수** 값은 반대로 틀을 줄입니다. 화면 가장자리를 잘라 내는 헤드유닛용으로, 잘린 가장자리를 다시 보이게 합니다(검은 띠가 조금 생깁니다).
- [직접 그리기 미러링](#self_draw)을 켰을 때 가장 정확합니다. 끈 상태라면 **연결된 상태에서** 값을 조정하세요. <span class="sp-mirror nav">‘ScreenOnAuto’ 미러링</span>에서는 미러링이 시작될 때 이미 설정되어 있던 음수 값이 화면을 키우는 대신 찌그러뜨릴 수 있습니다.

글자를 눌러 값을 입력합니다(0이 아닌 값을 저장하면 스위치가 켜집니다). 구분선 오른쪽의 스위치는 값을 그대로 둔 채 잠시 끄는 용도라 비교해 볼 수 있습니다.

> **💡 검은 띠를 아예 없애려면**
>
> Shizuku 또는 Root가 있다면 [휴대전화 화면을 차량 화면 비율에 맞추기](#root_display_override)를 켜세요. 휴대전화 화면을 영역과 같은 비율로 바꾸므로 미러링이 정확히 채워집니다. 띠도 없고 잘리는 부분도 없습니다. 켜져 있는 동안 이 두 조정은 잠시 멈춥니다.

### 야간 어둡게 {#category_night_dim}

#### 차량 화면 어둡게 {#night_dim}

밤에 차량의 미러링 화면을 어둡게 해서, 밝은 흰색 휴대전화 앱이 어둠 속에서 눈부시지 않게 합니다.

- <span class="sp-mirror legacy">‘ScreenOnAuto (Legacy)’ 미러링</span>이나 [직접 그리기 미러링](#self_draw)을 켠 경우에는 차량의 화면만 어두워집니다.
- 직접 그리기 미러링을 켜지 않은 <span class="sp-mirror nav">‘ScreenOnAuto’ 미러링</span>에서는 휴대전화 화면 위에 어두운 층을 덮는 방식이므로 **휴대전화도 함께 어두워집니다**. 이 경우 [다른 앱 위에 표시](#overlay_access) 권한이 필요합니다.
- 잠시 끄거나 켜려면 차량의 [야간 어둡게 버튼](#map_action_night_dim)을 쓰세요.

#### 어둡게 할 때 {#night_dim_trigger}

**차량이 야간 모드로 전환될 때**(기본값): 밤에는 어둡게, 낮에는 원래대로. **항상**: Android Auto가 연결되어 있는 동안 계속 어둡게.

#### 강도 {#night_dim_strength}

얼마나 어둡게 할지 정합니다: 10%–80%(기본값 50%). [야간 어둡게 버튼](#map_action_night_dim)도 이 값을 씁니다.

### 차량 화면에서 시작 {#category_car_start}

#### 백그라운드에서 미러링 시작 {#silent_car_start}

[차량에서 미러링을 시작](#auto_start_mirror)할 때 ScreenOnAuto 설정 화면이 휴대전화 앞에 나타나지 않고, 최근 앱에도 남지 않습니다. 캡처 대화상자는 여전히 나타납니다.

> **💡 팁**
>
> 여기에 [ADB로 부여한 미러링 권한](/docs/ko/grant-mirror-permission-via-adb/)까지 더하면 캡처 대화상자도 사라집니다. 차량에서 항목을 누르면 휴대전화에는 아무것도 나타나지 않고, 휴대전화를 건드리지 않아도 미러링이 바로 시작됩니다. 휴대전화 잠금을 해제할 때까지 차량에는 잠금 화면이 표시됩니다.

#### 전체 화면만 공유 {#full_screen_share_only}

Android 14부터 캡처 대화상자는 먼저 앱 하나를 공유할지 전체 화면을 공유할지 묻기 때문에, 매번 그 메뉴를 열어야 합니다. 이 설정을 켜면 대화상자가 전체 화면만 제시합니다. Android 14 이상에서 표시됩니다. 대화상자에서 앱을 골라 앱 하나만 미러링하고 있다면(ADB 권한 없이 하는 방법) 이 설정을 꺼 두세요. ADB로 권한을 부여했다면 대신 [이 앱만 미러링](#single_app_mirror)을 쓰세요.

그래도 두 선택지가 다 보인다면? Android 16의 개발자 옵션에 이를 되살리는 호환성 재정의(`OVERRIDE_DISABLE_MEDIA_PROJECTION_SINGLE_APP_OPTION`)가 있으니, 켜져 있지 않은지 확인하세요.

## 특권 기능 {#root_features}

이 페이지의 기능은 일반 앱이 건드릴 수 없는 시스템 설정을 바꾸기 때문에 [Shizuku](https://shizuku.rikka.app/) 또는 Root가 필요합니다. 각 기능은 미러링이 끝나면 휴대전화의 원래 설정을 되돌려 놓습니다.

### 연결 {#root_status}

맨 위의 상자는 Shizuku 또는 Root가 연결되어 있는지 보여 주며, 그 버튼으로 **액세스 허용**, **연결**, **연결 해제**를 합니다. 연결이 끊기면(예: Shizuku 재시작) 저절로 다시 연결됩니다.

ADB로 시작한 Shizuku 서버는 휴대전화를 USB로 차량에 연결하면 종료됩니다. [문제 해결](/docs/ko/how-to-use/#특권-기능-shizuku--루트)을 참고하세요.

### Root가 감지되지 않나요? {#root_force}

루트 관리자가 숨겨져 있거나 이름이 바뀌었다면 앱이 루트를 감지하지 못해 연결 상자에 루트가 나타나지 않습니다. 이 줄을 누르면 su에 직접 루트 권한을 요청합니다. 루트가 감지되지 않았고 아무것도 연결되지 않았을 때만 표시됩니다.

### 기능 {#category_root_features}

#### 휴대전화 화면 끄기 {#root_screen_off}

[자동 화면 어둡게](#auto_dim)가 작동할 때 어둡게 하는 대신 휴대전화의 백라이트를 끕니다. 자동 화면 어둡게가 켜져 있어야 합니다.

꺼지는 것은 화면뿐이고 **휴대전화가 절전 상태로 들어가지는 않습니다**. 앱과 시스템은 계속 실행되고, 미러링은 차량에 그대로 표시되며, 차량에서 휴대전화를 조작하는 것도 계속 됩니다. 다만 터치스크린이 화면과 함께 꺼지므로 **휴대전화 화면을 만져도 아무 반응이 없고**, 화면이 다시 켜지지도 않습니다.

화면을 되살리려면 차량의 [자동 어둡게 버튼](#map_action_auto_dim)을 누르거나, 미러링을 중지하거나 Android Auto 연결을 끊거나, 전원 버튼을 **두 번** 누르세요(처음 누르는 것이 시스템을 절전 상태로 만들기 때문입니다).

#### 실제 터치 입력 주입 {#root_touch_injection}

차량 화면의 터치를 실제 손가락 움직임으로 휴대전화에 보내므로 길게 누르기, 끌기, 여러 손가락 제스처가 작동하고, [터치 전달](#accessibility_access)의 접근성 서비스도 필요 없습니다. 모든 효과는 <span class="sp-mirror legacy">‘ScreenOnAuto (Legacy)’ 미러링</span>에서 누릴 수 있습니다. <span class="sp-mirror nav">‘ScreenOnAuto’ 미러링</span>은 Android Auto로부터 탭, 스크롤, 플링, 핀치만 받는데, 이는 Android Auto의 제한입니다.

#### 가상 터치스크린 {#root_virtual_touch}

그 터치를 가상 터치스크린 장치를 통해 전달하므로, 터치스크린을 직접 읽는 제스처 앱(GMD Gestures 등)도 터치를 받을 수 있습니다. [실제 터치 입력 주입](#root_touch_injection)이 켜져 있어야 합니다.

#### 휴대전화 다크 모드를 차량 주야간에 맞추기 {#root_follow_car_night}

미러링하는 동안 휴대전화의 라이트/다크 테마가 Android Auto의 주간/야간 모드에 맞춰 바뀌고, 끝나면 휴대전화의 원래 설정으로 돌아갑니다. Android 10 이상.

#### Android Auto에서 주야간 모드 읽기 {#root_car_night_from_aa}

앞의 스위치를 켜면 나타나며, <span class="sp-mirror nav">‘ScreenOnAuto’ 미러링</span>에 적용됩니다. 일부 휴대전화(예: 일부 Samsung 모델)에서는 앱에 전달되는 주야간 모드가 잘못되어 휴대전화가 차량에 맞춰 바뀌지 않습니다. 이 설정은 대신 Android Auto 자체의 주야간 상태를 읽습니다. 휴대전화가 이미 차량을 잘 따라간다면 꺼 두세요.

#### 미러링 중 글꼴 크기 {#root_mirror_font_scale}

미러링하는 동안 다른 글꼴 크기를 쓰고(예: 차량에서 글자를 더 크게), 끝나면 휴대전화의 원래 크기로 되돌립니다. 선택지는 휴대전화 설정 앱의 단계와 같습니다.

#### 미러링 중 탐색 모드 {#root_mirror_nav_mode}

미러링하는 동안 동작 탐색, 버튼 2개 탐색, 버튼 3개 탐색 중 하나로 바꾸고, 끝나면 되돌립니다(Android 10 이상). 예를 들어 세로형 헤드유닛의 분할 화면에서는 동작 탐색을 쓰면 앱이 쓸 공간이 더 넓어집니다. 휴대전화에 없는 모드는 사용할 수 없다고 표시됩니다.

#### 미러링 중 홈 화면 {#root_mirror_home}

미러링하는 동안 다른 런처를 휴대전화의 기본 홈 화면으로 쓰고, 끝나면 원래 런처로 되돌립니다. 차량용으로 배치한 홈 화면을 쓰고 싶을 때나, [화면 형태](#category_root_display)가 바뀌면 기본 런처가 아이콘을 재배치해 버리는 휴대전화(일부 Xiaomi HyperOS 모델)에 알맞습니다.

차량에 띠가 좌우에 있든(첫 번째 쌍) 위아래에 있든(두 번째 쌍) 작동하며, 큰 세로형 헤드유닛에서도 작동합니다(세 번째 쌍 — 휴대전화는 세로로 서며, [방향](#force_orientation_mode)을 자동 감지로 설정하면 저절로 세로로 고정됩니다). 휴대전화의 실제 화면 모양은 그대로이므로, 이 설정을 켜면 **휴대전화 자체**에는 반대 방향으로 띠가 생깁니다(차량에서 좌우에 띠가 있었다면 위아래에, 그 반대도 마찬가지). 이는 예상된 동작이며, 차량의 미러링은 정확히 채워집니다.

- 이것은 시스템 수준의 변경으로, 되돌리기 전까지 **다시 시작해도 유지됩니다**. 보통은 미러링을 중지하거나 연결을 끊으면 자동으로 되돌아갑니다.
- 휴대전화 화면 모양이 바뀌어 있는 동안에는 이 섹션 맨 위에 **복원** 버튼이 있는 호박색 알림이 나타납니다.
- 혹시 휴대전화 화면이 잘못된 모양으로 굳어 버렸는데 앱을 열 수 없다면, 컴퓨터에서 `adb shell wm size reset`과 `adb shell wm density reset`을 실행하세요.

#### 홈 화면에 되돌리기 바로가기 추가 {#root_display_shortcut}

홈 화면에 ‘화면 되돌리기’ 바로가기를 두어, 앱을 열지 않고 한 번 탭으로 휴대전화 화면을 되돌릴 수 있게 합니다.

#### 실제로 적용될 크기 {#root_display_derived}

차량 크기로부터 계산한 휴대전화 화면의 변경 크기와, 시스템이 실제로 받아들인 값입니다. 차량을 아직 측정하지 않았다면 다음에 Android Auto에서 미러링이 열릴 때까지 기다립니다.

#### 차량 화면 크기 {#car_size}

미러링마다 하나씩 있습니다(차량이 두 미러링에 서로 다른 크기의 영역을 줍니다). 기본값은 감지된 크기이며 **자동**으로 표시됩니다. 감지가 틀린 경우에만 바꾸세요. 너비와 높이는 한 대화상자에서 입력하며, 빈칸으로 두면 감지된 값을 씁니다(160–8192).

#### 휴대전화 표시 밀도 {#phone_density}

선택 사항이며 미러링마다 하나씩 있습니다(72–640 dpi). 숫자가 클수록 차량 화면의 글자와 버튼이 커지고, 작을수록 한 번에 더 많이 담깁니다. 너무 낮게 설정해 휴대전화의 짧은 쪽이 600dp를 넘으면 대부분의 앱과 시스템이 태블릿 레이아웃(두 열, 측면 탐색)으로 바뀝니다. 그렇게 될지는 입력하는 동안 대화상자가 알려 줍니다. 빈칸으로 두면 바꾸지 않습니다.
