# 사용 방법


이 안내서는 **휴대전화를 차량에 연결한 뒤 미러링을 시작하는 방법**을 다룹니다 — 두 가지
미러링 항목의 차이, 그리고 시작 절차를 단계별로 설명합니다.

> **ℹ️ 참고**
> **시작하기 전에** 다음을 확인하세요:
> - ScreenOnAuto가 설치되어 있고 Android Auto 런처에 ScreenOnAuto 항목이 보입니다.
> - 휴대전화에서 앱을 한 번 열어 요청되는 권한을 부여했습니다.

## 두 가지 미러링 항목

Android Auto의 앱 런처에는 미러링 항목이 **두 개** 표시됩니다. 둘 다 같은 휴대전화 화면을
미러링하며, 차이는 차량 화면에 *어떻게* 표시되는지에 있습니다:

![ScreenOnAuto 항목이 표시된 Android Auto 런처](/images/how-to-use/aa-launcher.png)

|  | <img src="/images/icon_launcher.png" width="48"><br>**ScreenOnAuto** | <img src="/images/icon_legacy.png" width="48"><br>**ScreenOnAuto (Legacy)** |
|---|---|---|
| 표시 방식 | 전체 화면 — 지도 영역을 대체합니다 | **화면이 충분히 큰 차량**에서는 분할 화면으로 **지도와 나란히** 표시될 수 있습니다. 화면이 작으면 지도가 그냥 뒤로 물러나고 미러링만 표시됩니다(지도를 **대체하지는** 않습니다) |

**ScreenOnAuto** — 전체 화면으로 지도 영역을 대체합니다:

![ScreenOnAuto 전체 화면 미러링](/images/how-to-use/nav-fullscreen.png)

**ScreenOnAuto (Legacy)** — 지도와 나란히 표시됩니다:

![지도와 나란히 표시된 ScreenOnAuto (Legacy)](/images/how-to-use/legacy-split.png)

둘 다 사용해 보고 헤드유닛에서 더 잘 동작하는 쪽을 쓰세요. 두 항목은 같은 미러링을
보여 주며 언제든지 서로 전환할 수 있습니다 — 미러링이 이미 실행 중이라면 다른 항목을
열었을 때 권한을 다시 묻지 않고 바로 표시됩니다.

> **💡 팁**
> 전에 **ScreenOnAuto**(전체 화면 항목)를 열었다가 이제 **ScreenOnAuto (Legacy)** 를
> 쓰고 싶다면, 먼저 차량 화면에서 지도 앱(예: Google 지도)을 연 다음 Legacy 미러링을
> 시작하세요. 그러면 지도 앱이 다시 차량 화면의 기본 지도로 설정되어, 지도 관련 기능이
> 전체 화면 미러링에 넘어가지 않습니다.

## 미러링 시작하기

### 자동 미러링 시작을 켠 경우 (권장)

1. 휴대전화의 앱에서 **자동 미러링 시작**을 켭니다(최초 1회 설정).
2. 휴대전화를 차량에 연결하고 Android Auto 런처에서 ScreenOnAuto 항목
   (<img src="/images/icon_launcher.png" width="24" align="center"> 또는
   <img src="/images/icon_legacy.png" width="24" align="center">)을 누릅니다.
3. 휴대전화에 화면 캡처 권한 대화상자가 자동으로 표시됩니다 — 휴대전화를 들고 **지금
   시작**을 누르세요:

   <img src="/images/how-to-use/capture-dialog.jpg" width="360" alt="휴대전화에 표시된 화면 캡처 권한 대화상자">

4. 휴대전화 화면이 헤드유닛에 나타납니다:

   ![헤드유닛에 미러링된 휴대전화 화면](/images/how-to-use/mirror-active.png)

> **ℹ️ 참고**
> 권한 대화상자는 Android의 요구 사항입니다 — 화면이 바뀔 때마다가 아니라 미러링을 시작할
> 때마다 한 번씩 표시됩니다. *자동 미러링 시작*이 꺼져 있으면 항목을 눌러도 미러링 화면만
> 열릴 뿐, 직접 시작하기 전까지는 아무것도 캡처되지 않습니다.

### 직접 시작하기

**자동 미러링 시작**을 꺼 두고 싶다면:

1. 휴대전화에서 ScreenOnAuto를 열고 **미러링** 스위치를 켠 다음, 권한 대화상자에서
   **지금 시작**을 누릅니다.
2. 차량 화면에서 ScreenOnAuto 항목 중 하나를 엽니다 — 미러링이 이미 실행 중이므로 바로
   표시됩니다.

(순서는 상관없습니다 — 항목을 먼저 열고 나중에 **미러링** 스위치를 켜도 됩니다.)

### 권한 대화상자 건너뛰기

매번 대화상자가 나오는 것이 번거롭다면 ADB로 한 번만 미리 권한을 부여할 수 있습니다 —
[ADB로 미러링 권한 부여](/docs/ko/grant-mirror-permission-via-adb/)를 참고하세요.

## 미러링 중지하기

다음 중 아무 방법이나 사용할 수 있습니다:

- **차량과의 연결 해제** — 미러링이 자동으로 중지됩니다(기본값인 *연결 해제 시 중지*
  설정).
- 휴대전화의 상시 알림에서 **미러링 중지**를 누릅니다.
- 앱에서 **미러링** 스위치를 끕니다.

## 문제 해결

- **항목은 열리는데 화면이 비어 있음** — 아직 미러링이 시작되지 않았습니다. 휴대전화에
  권한 대화상자가 떠 있는지 확인하거나 **미러링** 스위치로 시작하세요.
- **화면 주변에 검은 여백이 있음** — 휴대전화와 차량 화면의 화면비가 다르기 때문입니다.
  미러링 화면의 **가로 모드 강제** 버튼(또는 앱 설정의 **가로 모드 자동 강제**)을 쓰면
  대개 훨씬 잘 채워집니다. 얇은 틈이나 잘린 가장자리가 남는다면 **설정 → 고급 → 미러링
  너비 조정 / 미러링 높이 조정**으로 미세 조정하세요(양수 픽셀은 잘린 가장자리를 안으로
  당기고, 음수 픽셀은 검은 여백을 채우도록 바깥으로 밀어냅니다).
- **레이아웃이 바뀐 뒤 화면이 늘어나거나 찌그러져 보임**(예: 분할 화면에서 표시 영역이
  커지거나 작아질 때) — **설정 → 고급 → 미러링 크기 고정**을 켜세요. 그러면 화면이
  찌그러지는 대신 크기를 유지합니다(일부가 가려질 수 있습니다). 전체 화면
  **ScreenOnAuto** 항목에 적용됩니다.
- 차량 화면의 **Android Auto 내비게이션 바**는 Android Auto가 직접 그리는 것이라 앱에서
  숨길 수 없습니다.
