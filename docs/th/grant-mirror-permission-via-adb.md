# ให้สิทธิ์สะท้อนหน้าจอผ่าน ADB


โดยค่าเริ่มต้น Android จะแสดงกล่องโต้ตอบขอสิทธิ์ทุกครั้งที่ ScreenOnAuto เริ่มสะท้อนหน้าจอ คุณสามารถให้สิทธิ์ **บันทึกหน้าจอ (MediaProjection)** ล่วงหน้าด้วย ADB เพื่อไม่ให้กล่องโต้ตอบนี้ปรากฏอีก

สิทธิ์นี้ยังจำเป็นสำหรับ **สะท้อนเฉพาะแอปนี้** (Android 15 ขึ้นไป) ซึ่งใช้งานไม่ได้หากไม่มีสิทธิ์นี้

## สิ่งที่ต้องมี

- ติดตั้ง [ADB (Android Debug Bridge)](https://developer.android.com/tools/releases/platform-tools) ในคอมพิวเตอร์แล้ว
- เปิดการแก้ไขข้อบกพร่องผ่าน USB ในโทรศัพท์แล้ว (**การตั้งค่า → ตัวเลือกสำหรับนักพัฒนาซอฟต์แวร์ → การแก้ไขข้อบกพร่องผ่าน USB**)
- เชื่อมต่อโทรศัพท์ผ่าน USB (หรือ ADB ผ่าน Wi-Fi)

## ขั้นตอน

1. เปิดเทอร์มินัล (Command Prompt / PowerShell บน Windows)

2. ตรวจสอบว่า ADB มองเห็นอุปกรณ์ของคุณ:

   ```
   adb devices
   ```

   อุปกรณ์ของคุณควรแสดงเป็น `device` (ไม่ใช่ `unauthorized`)

3. ให้สิทธิ์:

   ```
   adb shell appops set idv.lzn.screenonauto android:project_media allow
   ```

4. เปิด ScreenOnAuto แล้วเริ่มสะท้อนหน้าจอ — กล่องโต้ตอบขอสิทธิ์ไม่ควรปรากฏอีก

## การเพิกถอนสิทธิ์

หากต้องการกลับไปใช้ลักษณะการทำงานเริ่มต้น (แสดงกล่องโต้ตอบทุกครั้ง):

```
adb shell appops set idv.lzn.screenonauto android:project_media default
```

## การแก้ปัญหา

- **`error: device unauthorized`** — มองหากล่องโต้ตอบ “อนุญาตให้แก้ไขข้อบกพร่องผ่าน USB ไหม” บนโทรศัพท์ แล้วแตะ **อนุญาต**
- **กล่องโต้ตอบยังปรากฏอยู่** — บังคับหยุด ScreenOnAuto แล้วเปิดใหม่ หากยังเป็นอยู่ ให้เพิกถอนแล้วให้สิทธิ์ใหม่ด้วยคำสั่งด้านบน
- **ติดตั้งแอปใหม่ (หรือสลับระหว่างช่องทาง Play กับไซด์โหลด)** — การถอนการติดตั้งจะล้างสิทธิ์ที่ให้ไว้ ให้เรียกใช้คำสั่งให้สิทธิ์อีกครั้งหลังติดตั้งใหม่
- **สิทธิ์ถูกรีเซ็ตหลังรีบูต** — ใน ROM บางตัว (เช่น MIUI/HyperOS) สิทธิ์ที่ให้ผ่าน `appops` จะไม่คงอยู่หลังรีบูต ให้เรียกใช้คำสั่งอีกครั้งหลังรีสตาร์ททุกครั้ง ADB ผ่าน Wi-Fi (การแก้ไขข้อบกพร่องผ่าน Wi-Fi) ช่วยให้ไม่ต้องเสียบสายทุกครั้ง แต่ไม่ได้ป้องกันการรีเซ็ต
