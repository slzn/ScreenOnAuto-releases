# นโยบายความเป็นส่วนตัว

ScreenOnAuto เป็นแอป Android ที่พัฒนาโดย Chih-En Liu สำหรับสะท้อนหน้าจอโทรศัพท์ไปยังเครื่องเสียงรถที่รองรับ Android Auto นโยบายนี้ครอบคลุมทั้งแอปและเว็บไซต์ screenonauto.lzn.idv.tw รวมถึงหน้าติดตั้งที่ `/join/`

**โดยสรุป: แอปไม่เก็บรวบรวม ไม่จัดเก็บบนเซิร์ฟเวอร์ใดๆ และไม่แชร์ข้อมูลส่วนบุคคลใดๆ**

## แอป

### ไม่มีการเข้าถึงอินเทอร์เน็ต

ScreenOnAuto ไม่ได้ขอสิทธิ์เข้าถึงอินเทอร์เน็ตของ Android จึงส่งข้อมูลออกจากโทรศัพท์ของคุณไม่ได้ แอปไม่มีไลบรารีโฆษณา การวิเคราะห์ข้อมูล การรายงานข้อขัดข้อง หรือการติดตามใดๆ และไม่ต้องมีบัญชี

### สิทธิ์ต่างๆ ใช้ทำอะไร

ทุกอย่างต่อไปนี้เกิดขึ้นบนโทรศัพท์ของคุณ สิ่งที่ออกจากโทรศัพท์จะไปถึงรถของคุณเท่านั้น ผ่านการเชื่อมต่อ Android Auto

| สิทธิ์ | ใช้ทำอะไร |
|---|---|
| บันทึกหน้าจอ (MediaProjection) | จับภาพหน้าจอโทรศัพท์หรือแอปเดียว แล้วแสดงบนหน้าจอรถ ไม่มีการบันทึกหรือจัดเก็บใดๆ |
| การเข้าถึงการแจ้งเตือน | อ่านเซสชันสื่อที่ทำงานอยู่ (กำลังเล่นอะไร เล่น/หยุดชั่วคราว ข้าม) สำหรับการควบคุมสื่อ ไม่มีการอ่านหรือจัดเก็บเนื้อหาของการแจ้งเตือน |
| บริการการช่วยเหลือพิเศษ | แปลงการแตะบนหน้าจอรถเป็นการแตะบนโทรศัพท์ และปุ่มกลับ / หน้าแรก / แอปล่าสุด ไม่ได้อ่านเนื้อหาบนหน้าจอ และไม่ได้ใช้เหตุการณ์การช่วยเหลือพิเศษที่ได้รับ |
| แสดงทับแอปอื่น | เลเยอร์ซ้อนทับของหรี่อัตโนมัติ ล็อกการวางแนว และหรี่ตอนกลางคืน |
| แก้ไขการตั้งค่าระบบ | ล็อกการหมุนหน้าจอระหว่างสะท้อนหน้าจอ บน Android 16 ขึ้นไปในโหมดแท็บเล็ต |
| Shizuku หรือ root (ไม่บังคับ) | ฟีเจอร์สิทธิ์พิเศษ: ปิดหน้าจอโทรศัพท์ ส่งการสัมผัสจริง ปุ่มนำทางของโทรศัพท์ และเปลี่ยนขนาดหน้าจอ ความหนาแน่น ธีม ขนาดตัวอักษร โหมดการนำทาง และตัวเรียกใช้งานเริ่มต้น (แอปหน้าแรก) ของโทรศัพท์ระหว่างสะท้อนหน้าจอ ค่าเดิมของโทรศัพท์จะถูกคืนเมื่อสิ้นสุดการสะท้อนหน้าจอ |

### สิ่งที่จัดเก็บ

การตั้งค่าของคุณ และค่าเดิมของโทรศัพท์ที่แอปจะคืนค่าหลังสะท้อนหน้าจอ (เช่น ขนาดหน้าจอ ธีม หรือตัวเรียกใช้งานเริ่มต้น) จะบันทึกไว้ในพื้นที่จัดเก็บของแอปเองบนโทรศัพท์ของคุณ การถอนการติดตั้งแอปจะลบข้อมูลเหล่านี้ หากเปิดการสำรองข้อมูลของ Android ไว้ Android อาจรวมการตั้งค่าเหล่านี้ไว้ในการสำรองข้อมูลในบัญชี Google ของคุณเอง หรือคัดลอกไปยังโทรศัพท์เครื่องใหม่เมื่อคุณย้ายข้อมูล เช่นเดียวกับที่ทำกับแอปส่วนใหญ่

### Google Play

หากคุณติดตั้ง ScreenOnAuto จาก Google Play ทาง Google อาจเก็บสถิติข้อขัดข้องและประสิทธิภาพตามการตั้งค่าอุปกรณ์ของคุณ และแชร์ให้นักพัฒนาในรูปแบบข้อมูลรวม (Android vitals) ซึ่ง Google เป็นผู้ดำเนินการภายใต้[นโยบายความเป็นส่วนตัวของ Google](https://policies.google.com/privacy)

## เว็บไซต์

### หน้าติดตั้ง (`/join/`)

หากต้องการเป็นผู้ทดสอบ คุณต้องลงชื่อเข้าใช้ด้วย Google บนหน้าติดตั้ง ระบบใช้เพียงอีเมลของบัญชีคุณ เพื่อเพิ่มคุณลงในรายชื่อผู้ทดสอบ Google Play ของรอบนั้น คุณจะไม่ได้รับอีเมลใดๆ และรายชื่อจะถูกลบเมื่อช่วงเวลาติดตั้งของรอบนั้นสิ้นสุด

การลงชื่อเข้าใช้ดำเนินการโดย Google: หน้าเว็บจะโหลดสคริปต์ลงชื่อเข้าใช้ของ Google ซึ่งอาจตั้งค่าคุกกี้ของ Google และได้รับที่อยู่ IP ของคุณ ภายใต้[นโยบายความเป็นส่วนตัวของ Google](https://policies.google.com/privacy) หลังลงชื่อเข้าใช้ โทเค็นที่ Google ส่งกลับมา ซึ่งมีรายละเอียดบัญชี Google ของคุณ เช่น อีเมล จะเก็บไว้ในพื้นที่จัดเก็บเซสชันของเบราว์เซอร์จนกว่าคุณจะปิดแท็บ หน้าเว็บจะส่งโทเค็นนี้ไปยังเซิร์ฟเวอร์ติดตั้ง (api.screenonauto.lzn.idv.tw) ซึ่งได้รับที่อยู่ IP ของคุณในแต่ละคำขอ แต่ไม่ได้บันทึกที่อยู่ IP หรืออีเมลของคุณ

### ส่วนอื่นทั้งหมด

นอกจากการลงชื่อเข้าใช้บนหน้าติดตั้ง เว็บไซต์ไม่ใช้การวิเคราะห์ข้อมูล ไม่มีการติดตาม และไม่มีคุกกี้ ธีมสว่าง/มืดที่คุณเลือกจะเก็บไว้ในพื้นที่จัดเก็บภายในของเบราว์เซอร์ เว็บไซต์โฮสต์บน GitHub Pages และโหลดฟอนต์จาก Google Fonts ดังนั้น GitHub และ Google จะได้รับที่อยู่ IP ของคุณในการให้บริการหน้าเว็บ ภายใต้นโยบายความเป็นส่วนตัวของแต่ละบริษัท

## รายงานข้อบกพร่องที่คุณส่ง

หากคุณเลือกส่งรายงานข้อบกพร่องหรือบันทึก (log) เช่น ผ่านลิงก์ Google Drive ใน GitHub issue รายงานนั้นอาจมีข้อมูลเกี่ยวกับอุปกรณ์และแอปในอุปกรณ์ของคุณ ข้อมูลนี้ใช้เพื่อตรวจสอบปัญหาของคุณเท่านั้น และจะถูกลบเมื่อการตรวจสอบเสร็จสิ้น GitHub issue เป็นสาธารณะ จึงไม่ควรโพสต์ข้อมูลส่วนบุคคลที่นั่น

## เด็ก

ScreenOnAuto ไม่ได้มุ่งเป้าไปที่เด็กอายุต่ำกว่า 13 ปี และไม่ได้เก็บข้อมูลจากผู้ใดโดยเจตนา

## การเปลี่ยนแปลง

หากนโยบายนี้เปลี่ยนแปลง เวอร์ชันใหม่จะเผยแพร่ในหน้านี้ และวันที่ “อัปเดตล่าสุด” ด้านล่างจะเปลี่ยนไป
