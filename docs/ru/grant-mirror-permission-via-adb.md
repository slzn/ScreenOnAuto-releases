# Выдача разрешения на дублирование через ADB

По умолчанию Android показывает окно разрешения каждый раз, когда ScreenOnAuto начинает дублирование экрана.
Разрешение **Захват экрана (MediaProjection)** можно выдать заранее через ADB, и окно больше не будет появляться.

Это также необходимо для функции **Транслировать только это приложение** (Android 15+), которая без него не работает.

## Что понадобится

- [ADB (Android Debug Bridge)](https://developer.android.com/tools/releases/platform-tools), установленный на компьютере
- Включённая отладка по USB на телефоне (**Настройки → Для разработчиков → Отладка по USB**)
- Телефон, подключённый по USB (или ADB по Wi-Fi)

## Шаги

1. Откройте терминал (командную строку / PowerShell в Windows).

2. Убедитесь, что ADB видит устройство:

   ```
   adb devices
   ```

   Устройство должно отображаться как `device` (а не `unauthorized`).

3. Выдайте разрешение:

   ```
   adb shell appops set idv.lzn.screenonauto android:project_media allow
   ```

4. Запустите ScreenOnAuto и начните дублирование — окно разрешения больше не должно появляться.

## Отзыв разрешения

Чтобы вернуть поведение по умолчанию (окно при каждом запуске):

```
adb shell appops set idv.lzn.screenonauto android:project_media default
```

## Устранение неполадок

- **`error: device unauthorized`** — найдите на телефоне окно «Разрешить отладку по USB?» и нажмите **Разрешить**.
- **Окно всё равно появляется** — принудительно остановите ScreenOnAuto и запустите снова. Если не помогло, отзовите и снова выдайте разрешение командами выше.
- **Приложение переустановлено (или вы перешли между каналами Play и ручной установки)** — удаление сбрасывает разрешение; после переустановки выполните команду выдачи ещё раз.
- **Разрешение сбрасывается после перезагрузки** — в некоторых прошивках (например, MIUI/HyperOS) разрешения `appops` не сохраняются после перезагрузки. Выполняйте команду после каждого перезапуска; ADB по Wi-Fi (беспроводная отладка) избавит от необходимости каждый раз подключать кабель, но сброс не предотвратит.
